# 裝修圖例翻卡遊戲

CNS 11567 設備圖例(消防、電器、給排水及衛生、電信電鈴電視、空調及機械)共 177 張,純 HTML/JS,無需安裝、無後端。

- **翻卡學習**:正面看圖例、點擊翻面看名稱,可標記「記住了/還不熟」(存在瀏覽器 localStorage)
- **問答遊戲**:看圖選名稱、看名稱選圖、混合;可選範圍與題數,結束後可練習答錯的題目
- **圖例總覽**:全部圖例可搜尋、依類別篩選

## 使用
直接開啟 `index.html`,或用 GitHub Pages 發佈(Settings → Pages → Branch: main / root)。

## 檔案
- `index.html` 主程式
- `cards.js` 圖例資料(名稱、類別、圖檔)
- `img/` 177 張圖例圖片(裁自「乙級建築物室內裝修工程管理研讀攻略(一)」所載 CNS 11567 表13~17)

> 圖例內容取自考試用教材,僅供個人學習,公開發佈前請留意著作權。
